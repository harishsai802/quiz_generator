Bulk Register Students from Excel

Upload an Excel file (.xlsx) with two columns: UUCMS ID and Name (a header row is optional — if there's no header, column A is treated as the UUCMS ID and column B as the Name). The UUCMS ID column is detected automatically even if there's an extra S.No/serial column, as long as the header mentions something like "UUCMS", "USN", "Roll No" or "Registration No" — add that header if you're unsure, to be safe.

Each student's login password is generated automatically as the last 4 digits of their UUCMS ID + the first 4 letters of their name (lowercase). For example, UUCMS ID U18UZ26S0180 and name Rahul → password 0180rahu. Their login ID is always their UUCMS ID (e.g. U18UZ26S0180), never a plain number.

If you type a name here, it's created automatically and used instead of the dropdown.
